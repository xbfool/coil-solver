# 实验脚本索引

每个脚本对应一次「先量再做」的判断。**结论列写的是当时的实测结果**，重跑就能复现。
注意：结论会随主算法演进过期（PROBE 那次就是活例子），标注的版本是它测的时候的底座。

## 盘面结构

| 脚本 | 量什么 | 结论 |
| --- | --- | --- |
| `board_stats.py` | 墙密度、度分布、两色平衡 | 无度 0/度 1 格；墙在两色上数量相等；墙密度稳定 33%；永远单连通 |
| `ham_vs_coil.py` | 哈密顿路径数 vs Coil 解数 | 5×5 空盘 8648 条哈密顿路径只对 32 个 Coil 解 —— **换空间的路是死的** |
| `branching.py` | 沿真解每步有几个候选活过剪枝 | 87% 的决策点只有一个候选 |
| `count_solutions.c` | 枚举全部有向解 | L99/L139 各只有 **1 个**解；L171 有 10 个 |
| `greedy_depth.c` | 贪心（不回溯）能覆盖多少 | 不管盘子多大都在 200~450 格卡死 —— 贪心+局部修补不成立 |

## 约束传播

| 脚本 | 量什么 | 结论 |
| --- | --- | --- |
| `forced_edges.py` / `verify_forced.py` | v9 时代的边传播 | 环模型自相矛盾（10 关里 6 关），是**建模**错了 |
| `propagate.c` | 无向传播（度约束 + 不成环 + 起点/终点色种子） | 真起点下定死 25~49% 的边；**奇数关**起点证伪率 44%，**偶数关 0%** |
| `probe.c` | 全局 probing / failed-literal；`--startxy` 给单个起点打分 | 假定起点后 probing 把必用边推到 35~38%；但**一个起点都证伪不了** |
| `directed.py` | 只有有向层（in/out + 互斥 + 2 环排除） | **几乎定不死任何东西**（in 定死 1/1604）—— 没有种子 |
| `joint.py` | 无向层 + 有向层联合传播，可注入种子 | 喂真解 25% 的 in 方向能推出 69%、50% 推出 93%；**规则够强，缺的是种子**。<br>而且种子的**分布**是决定性的：连续前缀（DFS 能给的）+0.0pt，随机散布 +45.9pt |

## 瓶颈分区（Mortal-Coil 那条路）

| 脚本 | 量什么 | 结论 |
| --- | --- | --- |
| `partition_stats.py` | 用 5 行瓶颈判据切割后的区域尺寸 | 切得极碎：L215 → 1294 个区域、最大才 57 格（1.5%） |
| `visit_pattern.py` | 真解把每个区域进出几次；段总数 vs 滑行步数 | 87% 的区域只进出一次；但**段总数只比滑行步数少 25%** —— 这就是别人慢的原因 |
| `transit.py` | 2 口区域的「零穿越解 ⇒ 必含端点」 | 零穿越解区域 **0 个**（区域太小，穿越总是存在） |
| `catalog.py` | 完整穿越目录（多段进出 + 端点 + 保守边界）→ 必用边 | 含端点模式时交集必为空（0%）；纯穿越能到 58~67% 但对含端点的 2 个区域是错的 |
| `region_pairs.py` | 拿 pure 目录筛 (起点区域, 终点区域) 对；`SYN=1` 测与传播的互补性 | 随机 60 对全活（筛不掉）；sound 的子集**被现有传播完全包含，净增 0 条边** |

## 怎么跑

```bash
python experiments/<脚本>.py [关号...]          # python 的
cc -std=gnu99 -O2 experiments/<脚本>.c -o bin/x  # C 的，然后 ./bin/x <关卡文件> [选项]
```

关卡在 `../coilbench/levels_all/`；带 soundness 检查的脚本要真解文件，
用 `./bin/<求解器> ../coilbench/levels_all/<关号> > <关号>.sol` 生成。

**所有涉及剪枝的实验都必须带 soundness 检查**（拿已知真解对照，真解用到的东西一条都不许被杀）。
这个仓库栽过跟头：v12 那次只看耗时不看输出，把「失败用了 12 秒」读成「12 秒解出」，
得出一整张错的对比表。
